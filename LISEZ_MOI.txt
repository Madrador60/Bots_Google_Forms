GOOGLE FORM STUDIO - GUIDE WINDOWS
==================================

Google Form Studio est un outil Windows pour analyser un Google Form public,
preparer des reponses, simuler un envoi et utiliser une interface graphique
simple depuis un PC Windows.


INSTALLATION RAPIDE
-------------------

Ouvre PowerShell, colle cette ligne, puis appuie sur Entree :

irm https://raw.githubusercontent.com/Madrador60/Bots_Google_Forms/main/install.ps1 | iex

Cette commande installe le projet dans ton dossier utilisateur, installe les
dependances Python, ajoute la commande `googleform`, puis lance l'application.

Si `googleform` n'est pas reconnu plus tard, ferme puis rouvre le CMD ou
PowerShell.


LANCER L'APPLICATION
--------------------

Apres installation, ouvre un CMD ou PowerShell et tape :

googleform

Commandes disponibles :

googleform          Lance l'interface graphique
googleform cli      Lance le mode terminal
googleform install  Installe ou reinstalle les dependances
googleform test     Lance les tests du projet
googleform help     Affiche l'aide


INSTALLATION MANUELLE
---------------------

Si tu as deja telecharge le dossier du projet :

1. Ouvre le dossier `Bots_Google_Forms`.
2. Double-clique sur `Installer_Dependances_Windows.bat`.
3. Double-clique sur `Lancer_GoogleForm_Studio.bat`.

Pour pouvoir taper `googleform` depuis n'importe quel CMD :

1. Double-clique sur `Installer_Commande_CMD_Windows.bat`.
2. Ferme puis rouvre le CMD ou PowerShell.
3. Tape `googleform`.


PREREQUIS
---------

- Windows 10 ou Windows 11
- Python 3.10 ou plus recent
- Pendant l'installation de Python, cocher `Add Python to PATH`

Lien officiel Python :

https://www.python.org/downloads/windows/


FONCTIONS PRINCIPALES
---------------------

- Analyse d'un Google Form public depuis son URL
- Affichage des questions dans une interface graphique
- Remplissage manuel
- Generation automatique de reponses
- Profils automatiques : prudent, equilibre, varie
- Simulation sans envoi
- Envoi unitaire
- Envoi en serie avec progression
- Pause, reprise et arret propre d'une serie
- Journal recent local
- Suppression de l'historique local depuis l'interface


TYPES DE QUESTIONS PRIS EN CHARGE
---------------------------------

- Reponse courte
- Paragraphe
- Choix multiple
- Liste deroulante
- Cases a cocher
- Echelle lineaire
- Grille a choix unique
- Grille a cases
- Date
- Heure


CONFIDENTIALITE
---------------

Chaque PC garde son propre historique local.

Les fichiers dans `logs/` et `runtime/` ne sont pas envoyes sur GitHub. Ils
sont crees uniquement sur la machine qui utilise l'application.

Le bouton `Effacer l'historique local` supprime :

- le journal recent;
- le journal du lanceur Windows;
- le dernier formulaire analyse;
- la derniere simulation sauvegardee.


VERIFICATION
------------

Pour verifier que le projet fonctionne :

Verifier_Projet_Windows.bat

Ou, si la commande `googleform` est installee :

googleform test

DEPANNAGE
---------

Python n'est pas reconnu :
- Installe Python depuis le site officiel.
- Relance l'installation en cochant `Add Python to PATH`.
- Ferme puis rouvre le CMD ou PowerShell.

La commande `googleform` n'est pas reconnue :
- Ferme puis rouvre le CMD ou PowerShell.
- Relance `Installer_Commande_CMD_Windows.bat`.

L'interface ne s'ouvre pas :
- Lance `googleform test`.
- Regarde le fichier `logs/google_form_studio.log`.


NOTES IMPORTANTES
-----------------

- Le formulaire Google doit etre public.
- Certains formulaires peuvent avoir une structure atypique.
- Google Forms peut changer son fonctionnement avec le temps.
- Utilise l'outil uniquement sur des formulaires que tu es autorise a tester
  ou administrer.
