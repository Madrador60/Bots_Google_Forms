GOOGLE FORM STUDIO - WINDOWS
============================

Lancement rapide
----------------
1. Double-clique sur `Installer_Dependances_Windows.bat` une premiere fois.
2. Double-clique sur `Lancer_GoogleForm_Studio.bat`.

Si Windows demande avec quel programme ouvrir le fichier, choisis
`Invite de commandes Windows` ou lance le fichier depuis un terminal.

Utilisation depuis le CMD
------------------------
Pour pouvoir lancer l'application depuis n'importe quel CMD:

1. Double-clique sur `Installer_Commande_CMD_Windows.bat`.
2. Ferme puis rouvre le CMD.
3. Tape `googleform`.

Commandes disponibles apres installation:
- `googleform` : lance l'interface graphique
- `googleform cli` : lance le mode terminal
- `googleform install` : installe les dependances Python
- `googleform test` : lance les tests
- `googleform help` : affiche l'aide

Installation en une ligne
-------------------------
Depuis PowerShell:

`irm https://raw.githubusercontent.com/Madrador60/Bots_Google_Forms/main/install.ps1 | iex`

Cette commande telecharge le projet depuis GitHub dans le dossier utilisateur,
installe les dependances Python, puis ajoute `googleform` au PATH utilisateur.

Commandes manuelles possibles
-----------------------------
- Interface graphique depuis ce dossier : `googleform`
- Interface graphique : `py -3 Interface_GoogleForm_Studio.py`
- Mode terminal : `py -3 Bot_GoogleForm_Intelligent.py`
- Tests : `py -3 -m unittest discover -s tests -p "test_*.py"`

Verification
------------
- Double-clic sur `Verifier_Projet_Windows.bat`

Prerequis
---------
- Windows 10 ou 11
- Python 3.10 ou plus recent
- Pendant l'installation de Python, cocher `Add Python to PATH`

Fonctions
---------
- Analyse d'un Google Form public a partir de son URL
- Remplissage manuel
- Remplissage automatique avec profils intelligents
- Delais minimum et maximum configurables
- Simulation sans envoi
- Envoi unitaire
- Envoi en serie avec progression et arret propre
- Journal recent des analyses, simulations et envois

Types pris en charge
--------------------
- Reponse courte
- Paragraphe
- Choix multiple
- Liste deroulante
- Cases a cocher
- Echelle lineaire
- Grille a choix unique
- Grille a cases
- Date
- Heure

Organisation du dossier
-----------------------
- `Bot_GoogleForm_Intelligent.py` : moteur principal
- `Interface_GoogleForm_Studio.py` : interface graphique
- `googleform.bat` : commande principale utilisable dans le CMD
- `install.ps1` : installateur PowerShell en une ligne
- `Installer_Commande_CMD_Windows.bat` : ajoute la commande au PATH utilisateur
- `Installer_Dependances_Windows.bat` : installe les dependances
- `Lancer_GoogleForm_Studio.bat` : lance l'application sur Windows
- `Verifier_Projet_Windows.bat` : compile et lance les tests
- `logs/` : journaux runtime
- `runtime/` : derniers snapshots et simulations
- `tests/` : tests automatiques

Confidentialite locale
----------------------
- Chaque PC garde son propre historique local.
- Les fichiers dans `logs/` et `runtime/` ne sont pas envoyes sur GitHub.
- Le bouton `Effacer l'historique local` supprime le journal recent, le journal du lanceur Windows, le dernier formulaire analyse et la derniere simulation.

Notes
-----
- Le formulaire doit etre public.
- Certains comportements Google Forms peuvent rester atypiques selon la structure du formulaire.
- Le journal runtime est stocke en local dans `logs/activity.jsonl`.
- Le journal du lanceur Windows est stocke dans `logs/google_form_studio.log`.
